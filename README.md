# HH Goa 2026 Frame / Builder ID

Live Link :- https://hh-goa-frame-lilac.vercel.app/

Web tool for Hacker House Goa 2026 Task #1.

- Format A: PFP frame
- Format B: Builder ID card (name, stack, generated builder class)
- Crew frame (1–3 teammates)
- Instant client-side canvas (no login)
- Download PNG + Share to X with `#FrameInGoa`
- HEIC / any aspect ratio / drag to reframe

## Run

```bash
npm install
npm run dev
```

## Deploy

```bash
npx vercel --yes
```

Set `NEXT_PUBLIC_SITE_URL` to the live URL after deploy (used for OG share pages).
